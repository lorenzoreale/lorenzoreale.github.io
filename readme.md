Lorenzo Reale Portfolio - Multi-Page Version

This folder contains the new multi-page structure for your portfolio. This architecture is designed to support your transition into freelancing/contracting by creating dedicated spaces for your Services and Projects.

Structure Overview

index.html: The homepage. Acts as a summary and a "hook" to get people to click further.

services.html: New. Specifically designed for potential clients. It explains what you can do for them (APIs, Data Cleaning, Dashboards) rather than just what languages you know.

projects.html: Separates your "Real Job" work (Costain/Energy) from your "Lab" work (GitHub/Learning).

about.html: Tells the story of the transition from Data -> Engineering.

contact.html: Simple contact card.

style.css: The shared styling file. Edit this file to change colors or fonts across the entire website instantly.

script.js: Handles the mobile menu toggle and dynamic footer year.

How to Use

Create a new folder on your computer (e.g., Portfolio-v2).

Create the 7 files listed above inside that folder.

Paste the code provided into each respective file.

Open index.html in your browser to view the site.

Key Customizations Needed

Before publishing, please open the files and search for TODO or fill in these specific details:

Links: Update href="#" in contact.html and index.html to point to your actual LinkedIn and GitHub profiles.

Email: Update mailto:your-email@example.com in contact.html.

Images: I have not included <img> tags to keep the code clean, but you should consider adding a photo of yourself on the about.html page.

Deployment

Since this is a static site (HTML/CSS/JS), you can host this exactly the same way as before (GitHub Pages, Netlify, Vercel). Just ensure all files are in the root directory of your repository.
